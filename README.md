# Eye Movement-Based Mouse Control System

## Overview

This project focuses on the design and implementation of a computer mouse control system based on eye movements. It explores two approaches: Electrooculography (EOG), using electrical signals generated by eye movements, and camera-based eye tracking using computer vision.

The objective is to provide a hands-free human-computer interaction solution with potential applications in accessibility and assistive technologies.

## Objectives

- Acquire eye movement signals using Ag/AgCl electrodes.
- Amplify and condition EOG signals using the AD620AN instrumentation amplifier.
- Process biological signals using the STM32F429I-DISC1 microcontroller.
- Detect eye movements and translate them into cursor control commands.
- Explore camera-based eye tracking as an alternative approach.

## Hardware Components

- STM32F429I-DISC1 development board
- AD620AN instrumentation amplifier
- Ag/AgCl electrodes
- Analog signal conditioning and filtering circuits
- Computer with a camera for the alternative eye-tracking approach

## Software and Technologies

- STM32CubeMX

- Computer Vision
- USB Human Interface Device (HID)

## Methodology

The EOG approach involves acquiring electrical signals from electrodes placed around the eyes, amplifying and filtering the signals, converting them into digital values, and processing them to detect eye movements. The detected movements are then translated into cursor control commands.

Because noise affected the EOG signal, an alternative approach based on an RGB camera and MediaPipe FaceMesh was explored. This method detects facial and iris landmarks to estimate gaze direction and control cursor movement in real time.

## Results

The camera-based approach demonstrated functional cursor control for the main gaze directions. The project also highlighted the challenges of EOG signal acquisition, particularly noise and signal stability.
